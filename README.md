# 🏥 Hospital Emergency Dashboard

## 📌 Project Overview

The **Hospital Emergency Dashboard** is a data analytics project that provides an interactive view of hospital emergency department performance. It helps analyze patient visits, waiting times, admission status, demographics, and department referrals, enabling better decision-making through data visualization.


## 🎯 Objective
The objective of this project is to:

* Monitor emergency department performance.
* Analyze patient flow and waiting times.
* Identify trends in patient demographics.
* Track admission and referral statistics.
* Support data-driven healthcare decisions.

## 🛠️ Tools & Technologies

* **Microsoft Excel**
* **Dashboard & Charts**
* **Data Cleaning**
* **Data Analysis**

## 📊 Dashboard Features

* Total number of emergency patients
* Average patient waiting time
* Patient admission status
* Age group analysis
* Gender distribution
* Department referral analysis
* Monthly emergency visit trends
* Interactive dashboard with filters

## 📈 Key Insights

* Monitor emergency patient volume over time.
* Analyze average waiting time for patients.
* Compare admitted and non-admitted patients.
* Understand patient demographics by age and gender.
* Identify departments receiving the highest referrals.
* Support hospital management with actionable insights.
